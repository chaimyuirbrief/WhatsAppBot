Backup & restore 💾

        
Everything needed to stand this bot up again on another machine, in one
        encrypted file: settings, admin accounts, the WhatsApp link, and the key that decrypts
        your saved secrets. Logs are left out.

          This file is a working copy of your WhatsApp account. Anyone with it and the passphrase

Restore from a backup

        
Replaces the settings and session on this machine. Disconnect WhatsApp first,
        and restart the bot afterwards. Whatever is here now is copied aside, not deleted.

        

          
          
        

        

        

          
          
        

        


        
Moving to a new machine

        
# on the old machine
node bin/backup.js create -o ~/wa-backup.wabak

# on the new one, after ./install.sh
node bin/backup.js restore ~/wa-backup.wabak
npm start
